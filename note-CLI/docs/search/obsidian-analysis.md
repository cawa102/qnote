# Obsidian 分析レポート

> ターミナルベースのノートCLIアプリ開発に向けた、Obsidianの強み・特徴・ユーザー魅力の包括的分析

---

## 1. 概要・市場ポジション

Obsidianは2020年にリリースされたローカルファーストのナレッジマネジメントアプリで、プレーンテキストのMarkdownファイルを基盤としている。

### 主要数値（2025年時点）

- **月間アクティブユーザー**: 150万人以上（前年比22%成長）
- **コミュニティプラグイン数**: 2,700以上
- **Discordコミュニティ**: 11万人以上
- **推定年間収益**: 約2,500万ドル（オプションのSync/Publishから）
- **チーム規模**: 18人（VCなしのブートストラップ企業）
- **平均使用時間**: 1日43分
- **サブスク更新率**: 90%以上
- **推定評価額**: 3〜3.5億ドル

出典: [Fueler - Obsidian Statistics](https://fueler.io/blog/obsidian-usage-revenue-valuation-growth-statistics), [GetLatka](https://getlatka.com/companies/obsidian.md)

## 2. コア機能の分析

### 2.1 ローカルファースト・プレーンテキストMarkdown

**最も重要な設計思想**

- すべてのノートはローカルデバイス上にプレーンテキストのMarkdownファイルとして保存
- プロプライエタリなフォーマットを一切使用しない
- インターネット接続なしで完全に動作
- Obsidianが消滅しても、任意のテキストエディタでデータにアクセス可能
- **データ所有権100%がユーザーにある**

**ユーザーへの魅力**:
- ベンダーロックインへの恐怖がない
- Notionのようなクラウドサービスへのデータ依存を回避
- プライバシーが根本的に保護される（サーバーにデータが送信されない）
- 将来にわたるデータの永続性が保証される

出典: [Obsidian公式](https://obsidian.md/), [Pixno Blog](https://photes.io/blog/posts/is-obsidian-a-local-first-app)

### 2.2 双方向リンク（Backlinks）

**ナレッジグラフの中核機能**

- `[[ノート名]]`構文で内部リンクを作成
- リンク先に自動的にバックリンクが生成される
- 明示的リンクに加え、「未リンクの言及（Unlinked Mentions）」も検出

**バックリンクの種類**:
- **コンテキストバックリンク**: ノート本文中に埋め込まれ、文脈と深さを提供
- **明示的バックリンク**: ノート末尾に明確に定義され、アイデア間のパスを辿る

**ユーザーへの魅力**:
- 孤立したノートを動的に相互接続されたアイデアのウェブに変換
- 手動インデックス不要でナレッジの関係性をナビゲート
- Zettelkasten方法論との高い親和性

出典: [DeepWiki - Internal Links](https://deepwiki.com/obsidianmd/obsidian-help/4.2-internal-links-and-graph-view), [Jordan Robison](https://www.jordanrobison.net/p/unleash-power-backlinks-obsidian-knowledge-graph)

### 2.3 グラフビュー

- ノート間の接続を視覚的に表現
- パターンやギャップの発見に役立つ
- フィルター機能でタグ、フォルダ、検索クエリによる絞り込み可能
- ローカルグラフ（現在のノートに関連するものだけ表示）とグローバルグラフの両方を提供

**ユーザーへの魅力**:
- 知識の「鳥の目」ビューを提供
- ハブとなるノート（中心的なアイデア）を視覚的に特定
- 思考の構造を直感的に把握

出典: [Obsidian Help - Graph view](https://help.obsidian.md/plugins/graph)

### 2.4 テンプレートとデイリーノート

**テンプレート機能**:
- 事前定義されたテキスト、フォーマット、リンク、タグをノートに適用
- `{{date}}`、`{{time}}`などの動的タグをサポート
- ノート作成の一貫性と効率を向上

**デイリーノート**:
- コアプラグインとして毎日新しいノートを自動作成
- テンプレートとの連携で日々のルーティンを構造化
- ジャーナリング、タスク管理、振り返りに活用

**Zettelkasten ワークフロー**:
- **Fleeting Notes**: 一時的なアイデアの素早いメモ
- **Literature Notes**: 読書・記事の要約
- **Permanent Notes**: 原子的で再利用可能なアイデア（相互リンク）

出典: [Obsidian Templates Guide](https://facedragons.com/productivity/obsidian-templates-with-examples/), [Danny Blog](https://dannb.org/blog/2022/obsidian-daily-note-template/)

### 2.5 プラグインエコシステム

**エコシステムの規模と特徴**:
- **コアプラグイン**: Obsidianチームが開発、安定性が高い（バックリンク、グラフビュー、検索、テンプレート等）
- **コミュニティプラグイン**: 2,700以上、ユーザーが開発するサードパーティ拡張

**人気カテゴリ**:
- カレンダー管理
- タスク管理（Tasksプラグイン）
- バージョン管理
- コードハイライト
- データビュー（Dataviewプラグイン - SQLライクなクエリ）
- カンバンボード
- マインドマップ
- Excalidraw（手書き描画）
- 公開・パブリッシュ
- スペースドリペティション（暗記学習）

**ユーザーへの魅力**:
- 「Obsidianは何にでもなれる」という柔軟性
- 自分のワークフローに完全にカスタマイズ可能

出典: [Obsidian Plugins](https://obsidian.md/plugins), [ObsidianStats](https://www.obsidianstats.com/)

### 2.6 その他のコア機能

- **キャンバス**: ノートをビジュアルに配置・接続するフリーフォームの空間
- **データベース**: 2025年に追加された新機能
- **検索**: 強力な検索演算子によるノート横断検索
- **タグシステム**: 階層タグ（`#topic/subtopic`）をサポート
- **コマンドパレット**: キーボードショートカットによる素早い操作
- **マルチプラットフォーム**: Mac、Windows、Linux、iOS、Android

## 3. ユーザーがObsidianを選ぶ理由

### 3.1 プライバシーとデータ所有権

> 「Notionはクラウドの遅延と企業サイロにデータが閉じ込められる感覚にぶつかる」

- ローカルファーストは最大の差別化要因
- プレーンテキストMarkdownによるベンダーロックイン回避
- アカウント不要（有料サービスを使わなければ）

### 3.2 速度と安定性

- クラウドベースのNotionと比較して圧倒的に高速
- オフライン動作が標準
- ネットワーク遅延に一切影響されない

### 3.3 カスタマイズ性

- テーマ、プラグイン、CSSスニペットによる無制限のカスタマイズ
- Logseqはアウトライナーに特化、ObsidianはプラグインとビジュアルグラフでExtensibility重視

### 3.4 深い思考のためのツール

- 研究者、ライター、開発者に特に人気
- Zettelkasten、GTD、PARAなど様々な方法論に適応
- 「ノートを取る」のではなく「思考を鍛える」というブランディング

### 3.5 無料で使える

- 個人利用は完全無料（機能制限なし）
- 商用利用も2024年から無料化
- 有料はSync（$4/月）とPublish（$8/月）のオプションのみ

出典: [TheBusinessDive](https://thebusinessdive.com/obsidian-review), [Lindy.ai](https://www.lindy.ai/blog/obsidian-review), [G2 Comparison](https://learn.g2.com/obsidian-vs-notion)

## 4. Obsidianの弱点・ペインポイント

### 4.1 急勾配の学習曲線

- 高いカスタマイズ性が初心者には圧倒的
- YAMLフロントマターやメタデータの概念が非技術者には難解
- 「何をすればいいか分からない」状態に陥りやすい

### 4.2 プラグイン過多問題

- 2,700以上のプラグインの中から最適なものを見つけるのが困難
- プラグインの組み合わせによる予期しない競合
- プラグインに時間を費やし、ノート取り本来の目的から逸脱する「プラグイン沼」

### 4.3 同期の問題

- デフォルトでは同期機能なし
- 公式Syncは有料（$4/月）
- サードパーティ同期（iCloud、Dropbox等）は不安定な場合がある
- 大きなファイルでの同期トラブルが報告されている

### 4.4 コラボレーション機能の欠如

- チーム共同編集はNotionに大きく劣る
- リアルタイム共同編集は未対応
- Publishはあくまで読み取り専用の公開

### 4.5 デザイン・UI

- NotionやCraftと比較して視覚的な洗練さに欠ける
- デフォルトテーマが地味（カスタムテーマで改善可能）

### 4.6 特定機能の不足

- PDF注釈が弱い
- 手書きサポートなし
- テーブル編集が不便（Markdown制約）
- 画像管理が煩雑

出典: [Obsidian Forum - Problems](https://forum.obsidian.md/t/problems-positives-and-negatives-of-obsidian/90481), [OriginalMacGuy](https://www.originalmacguy.com/obsidian-the-good-the-bad-the-ugly/), [Medium - Theo James](https://medium.com/@theo-james/did-you-try-to-use-obsidian-but-then-stopped-youre-not-alone-903764869396)

## 5. ターミナルベース実装に最も関連する機能

### 5.1 必須で取り込むべき機能

| 機能 | 理由 | CLIでの実現性 |
|------|------|---------------|
| **プレーンテキストMarkdown** | Obsidian最大の強み、CLIと完全に親和 | 非常に高い |
| **双方向リンク `[[]]`** | ナレッジグラフの中核 | 高い（パーサーで実装） |
| **バックリンク表示** | ノート間の関係性把握に不可欠 | 高い（grep/索引で実装） |
| **タグシステム** | ノートの分類・検索に必須 | 非常に高い |
| **全文検索** | 大量ノートでの情報発見 | 非常に高い（ripgrepベース） |
| **デイリーノート** | ジャーナリング・習慣化に重要 | 非常に高い |
| **テンプレート** | ノート作成の一貫性 | 非常に高い |
| **ローカルファースト** | CLIの本質的特性 | 自動的に達成 |

### 5.2 ターミナルで独自の価値を出せる機能

| 機能 | アプローチ |
|------|-----------|
| **グラフビュー** | TUIでのASCII/ブロック文字グラフ、または外部ブラウザ連携 |
| **コマンドパレット** | CLIの得意分野（fzfライクなインタラクション） |
| **Vimキーバインド** | ターミナルネイティブで実現可能 |
| **Git連携** | バージョン管理の自然な統合 |
| **パイプライン処理** | UNIXフィロソフィーに基づく他ツールとの連携 |
| **スクリプタビリティ** | シェルスクリプトによる自動化 |

### 5.3 CLIでは省略・簡略化すべき機能

- キャンバス（ビジュアルツールはGUI向き）
- テーマ・CSS装飾（ターミナルのカラースキーム程度で十分）
- 大規模プラグインエコシステム（シンプルさを維持し、コアに集中）
- WYSIWYG編集（ターミナルでは$EDITORに委任）

## 7. 総合サマリー

### Obsidianの成功要因

1. **ローカルファースト + プレーンテキスト**: データ所有権と永続性の保証が最大の差別化要因
2. **双方向リンク**: 単なるノートアプリからナレッジマネジメントツールへの昇華
3. **プラグインエコシステム**: 無限のカスタマイズ性が多様なユーザーニーズに対応
4. **コミュニティ**: 活発なコミュニティがエコシステムを支える好循環
5. **無料モデル**: 低い参入障壁と高いリテンション

### ターミナルCLIアプリへの示唆

- **必ず取り入れるべき**: ローカルファースト、プレーンテキストMarkdown、双方向リンク、バックリンク、タグ、全文検索、デイリーノート
- **CLIならではの強み**: Git統合、パイプライン処理、高速操作、スクリプタビリティ、$EDITOR連携
- **避けるべき**: プラグインの複雑さ、過度なUI装飾、GUIでしか活きない機能
- **Obsidianの弱点を攻める**: 学習曲線の簡素化、シンプルさの維持、同期の簡便化（Git）、起動の軽さ

> Obsidianの思想「Your notes are yours（ノートはあなたのもの）」はCLIツールと完全に一致する。ターミナルベースのツールは、この思想をさらに純粋な形で体現できる可能性がある。
